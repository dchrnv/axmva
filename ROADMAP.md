# Roadmap

Статус: `hypothesis` — план, не факт; меняется по ходу работы. Открытые вопросы по конкретным пунктам — в `Deferred.md`, здесь не дублируются, только ссылки по номеру.

## Фаза 0 — Кристаллизация структуры (текущая, с 2026-10-24)

- Изучить собранный материал (внешний архив `AXMV2/`, Obsidian vault).
- Стабилизировать `Invariants.md` и `specs/Passport.md`.
- Разобрать открытые вопросы `Deferred.md` (D1–D16): для каждого — нужен ли для цели проекта, или можно обойтись без него.

## Фаза 1 — Первый элемент

- Выбрать путь и `kind` для первого элемента (`guides/Passport-guide.md`, шаг 0).
- Пройти лестницу `stub → training → connected` для него.
- По факту первого элемента с кодом: решить D12 (гайды для элементов) и D6 (нужна ли формальная схема самого passport).
- Решить D7 (нужен ли отдельный модуль-запускатель проверок, или один скрипт).

## Фаза 2 — Сборка из нескольких элементов

- Скан строит `index.yaml` (I1) — список членов руками не ведётся.
- `assembly_hash` и диапазоны совместимости `passport_schema` между элементами (I9).
- Первые связи `links_in` + `gate` между элементами (I15–I17).

## Направления без срока

Зависят от появления конкретной потребности, не планируются заранее:

- D9 — мастер-ключ и шифрование: есть нерешённые противоречия с `change_policy`, нужно разрешить до переноса идеи.
- D15 — роли доступа и уровень «вето».
- D10 — рассинхронизация версий элементов (неактуально, пока всё в одном дереве).
- D16 — журнал и воспроизведение (возможно, деталь реализации, не поле passport).
