# AXMVA — Axiom, версия Anthropic

Рабочее имя проекта: **axmv2**. Папка `AXMVA` это место проекта: здесь хранится всё собственное, без истории и дублей. При публикации на GitHub под другим именем папку достаточно переименовать.

Материалы-источники (идеи из старых линий, справочники, проектные заметки axmg) остаются в `AXMV2/` и сюда не копируются: документы отсюда ссылаются на них.

Порядок работы (стратегия пользователя, 2026-10-24): изучить весь собранный материал, выкристаллизовать окончательную структуру, только после этого реализация. `axmg` это готовая промежуточная библиотека, идею она подтвердила.

## Структура
- [[Invariants]] (корень): нейминг и неизменяемые правила проекта.
- [[Deferred]] (корень): отложенные решения, которые всплыли по пути.
- [[Notebook]] (корень): черновой блокнот обсуждений по шагам, до того как решение попадёт в Invariants/Deferred/specs.
- `specs/`: спецификации. Сейчас [[Passport]] (поля, kind, состояния, проверки, версии).
- `guides/`: гайды. Сейчас [[Passport-guide]] (как написать passport для нового элемента).
- `drafts/`: рабочие черновики по конкретным элементам, до того как они стабилизируются в specs/passport. Сейчас: `axmv2-core-passport.md` (паспорт ядра-архиватора, основа), `axmv2-time-module.md` (модуль времени), `axmv2-deck-map.md` (надстройка-генератор гипотез через карты Таро, статус арканов определён в core-passport: это не архитектура, в работу идёт только то, что проходит "правило линзы").

Остальные папки создаются, когда в них появится первый документ. Имена папок и файлов латиницей (N9).

## Шкала статусов (одна для всех документов)
`done` | `hypothesis` | `analogy` | `fantasy`. Подробнее в [[Invariants]] (N5).

## Правила
- Документ сюда попадает только со ссылкой на источник (в `AXMV2/` или в проектные заметки).
- Статус источника переносится точно, не повышается.
- Одна версия документа в одном файле. Решения фиксируются журналом, копии не хранятся.
- Принятые принципы проекта: `AXMV2/Идеи/Принципы и правила дизайна.md`.
