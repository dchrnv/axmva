# input/

Папка для ручного ввода: сюда кладётся файл (корпус текста, документ), который модель читает как первую порцию. Это физическая реализация транспорта для `elements/external-input/passport.yaml` (`kind: external`) — паспорт описывает контракт («порция + тег источника»), эта папка — просто один конкретный способ его выполнить.

Не единственный способ. Позже данные могут приходить из камеры, микрофона и других сенсоров — каждый такой источник это свой транспорт, своя идентичность для `gate` (I16 в `Invariants.md`: источник определяет связь, не содержимое сообщения). Эта папка не станет универсальным входом для всех сенсоров — у камеры будет свой путь, не подпапка здесь.

Формат файлов, правило нарезки на порции и тег источника для этой конкретной папки — открытый вопрос, см. `elements/external-input/passport.yaml` → `open_questions`.
