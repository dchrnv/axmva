# axmv2: модуль времени (основа)

Дата: 2026-10-27. Принято как основа. Метки: **[есть]** уже в axmg, **[гипотеза]** моя формулировка, ещё не проверена, **[аналогия]** взято из философии времени (даёт вид времени, проверять надо на данных).

Идея: внутри модели времени нет, но оно не может не быть, поэтому нужны разные виды времени. Модуль времени это библиотека поверх ядра. Колесо остаётся для него источником тиков.

## Виды времени

| # | Вид | Источник | Функция | Статус |
|---|---|---|---|---|
| 1 | Порядковое («раньше / позже») | Аристотель, B-ряд Мактаггарта | номер оборота, штамп на границе | [есть] |
| 2 | Относительное «сейчас» | A-ряд Мактаггарта | возраст = сейчас − `last_touched`, считается на лету, не хранится | [гипотеза] |
| 3 | Внутреннее | Бергсон, длительность | возраст в накопленном S-growth, а не в оборотах | [гипотеза] |
| 4 | Три настоящих | Августин, Гуссерль (ретенция, протенция) | память = топология (LTM), внимание = фокус (STM), ожидание = прогноз следующего | [гипотеза], ожидания нет |
| 5 | Циклическое | Платон | период появления токена по оборотам | [гипотеза] |
| 6 | Стрела | Больцман, Пригожин | необратимость: журнал только дописывается, привыкание задаёт направление | [есть] журнал, остальное [гипотеза] |
| 7 | Локальное | Лейбниц, относительность | часы у каждой полки и пака, синхронизация по общим событиям | [гипотеза] |

## Набор для v1

Виды **1, 2, 3 и 5**. Остальные остаются пометками.

- Вид 3 снимает вопрос про размер порции: оборот это порция входа (64 КБ корпуса или одна реплика агента), и в оборотах возраст несравним, а в накопленном S-growth сравним.
- Вид 5 возможный источник «лукавства K=3»: токен, возвращающийся реже чем раз в 3 оборота, умирает и рождается заново.

## Минимальный API [гипотеза]

```rust
fn stamp(&self) -> u32                    // порядковое
fn age(&self, t: TokenId) -> u32          // сейчас − last_touched
fn age_inner(&self, t: TokenId) -> f32    // inner[now] − inner[last_touched]
fn period(&self, t: TokenId) -> Option<u32>
```

`inner` это один массив по оборотам: накопленный S-growth на конец каждого оборота.

## Проверка паспортом ядра (правило линзы)

- `stamp`, `last_touched`: [есть] в Колесе.
- `inner`: S-growth уже считается на каждом обороте, нужно лишь копить его в массив.
- `period`: нужна история оборотов, в которых токен был в свёртке, то есть связана с развилкой «общая история» из `axmv2-tarot-wheel-10.md`.

## Развилки и открытое

- **Развилка:** жёсткое окно K=3 в Смерти (проверено на Гите: сжатие нового текста лучше на 13–23%) против ретенции с затуханием. Затухание это гипотеза, и менять проверенное правило можно только после теста против K=3.
- «Лукавство малых чисел» всё ещё не найдено (кандидаты: K=3 как фильтр низких частот, метка не обновляется у неизменного префикса).
- Нужно решить, считать ли оборот агента равным одному событию или оставить порцию входа (вид 3 это смягчает, но не отменяет).
- Протенция (ожидание): по карте колоды её даёт Отшельник (карта ожиданий до оборота, read-only, по замороженной полке); в модуле времени отдельного выхода не нужно. Статус: набросок.
